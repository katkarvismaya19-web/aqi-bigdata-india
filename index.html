How clean is the air in India's cities?

Five years of government air quality data for 26 Indian cities, from 2015 to 2020, processed with Hadoop and Apache Spark. See which cities are most polluted, how the air changes through the year, what the COVID-19 lockdown did, and the live AQI today.

Open the dashboard View the code

What five years of data show

The analysis covers 29,531 daily readings from the Central Pollution Control Board (CPCB). Air quality is worst from November to January, when cold, still air traps pollution, and best during the monsoon.

How it was built

A big data pipeline that runs on a Hadoop cluster with Apache Spark, from raw files to the published dashboard.

Stack: Hadoop HDFS, Apache Spark 4.2 (PySpark, Spark SQL, MLlib), Parquet, Docker, Python, pandas, Matplotlib, JavaScript, GitHub Pages.

  1. Store the data in HDFS

    The raw CPCB dataset is loaded into a Hadoop HDFS cluster (NameNode and DataNode, run with Docker).

  2. Process it with Spark

    Spark reads the data from HDFS into distributed DataFrames, removes duplicates and invalid readings, and adds year, month and season.

  3. Analyse with Spark SQL

    City rankings, monthly and seasonal trends, AQI categories, pollutant correlations, and the 2020 lockdown compared with 2019.

  4. Predict AQI with MLlib

    Linear Regression, Decision Tree, Random Forest and Gradient Boosted Trees are trained and compared. Random Forest scores R² 0.908.

  5. Recalculate every day's AQI

    Each city-day's AQI is computed from raw pollutant levels with the official CPCB sub-index method, filling 895 days with no recorded AQI.

  6. Write back and publish

    Results are saved to HDFS as Parquet, partitioned by city, and exported to the dashboard, which also shows live AQI for all 26 cities.

About the data

Historical data: Air Quality Data in India (2015–2020) on Kaggle, compiled from Central Pollution Control Board data. AQI follows the CPCB National Air Quality Index: each pollutant gets a sub-index, and the day's AQI is the highest one. Live AQI uses modelled pollutant levels from the Copernicus Atmosphere Monitoring Service via Open-Meteo, converted with the same formula, so it can differ from official station readings.
