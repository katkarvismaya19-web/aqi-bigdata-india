# Dataset

This project uses **city_day.csv** from the Kaggle dataset
**"Air Quality Data in India (2015 - 2020)"** by Vopani (Rohan Rao), compiled from
Central Pollution Control Board (CPCB) data.

1. Download it from Kaggle: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india
2. Unzip and copy `city_day.csv` into this `data/` folder.

The file is about 2.5 MB: 29,531 rows, 26 cities, 1 Jan 2015 to 1 Jul 2020.
It is not committed to this repository; check the dataset licence on Kaggle before redistributing it.
